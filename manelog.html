マネログ プライバシーポリシー

対象アプリ: マネログ(Android アプリ / パッケージ名 jp.manelog.app)

提供者(デベロッパー): Primary Dice

制定日: 2026年7月21日 / 最終更新日: 2026年8月17日(広告の表示について追記)

本プライバシーポリシー(以下「本ポリシー」)は、上記提供者(以下「当方」)が提供する Android アプリケーション「マネログ」(以下「本アプリ」)における、利用者の情報の取り扱いについて定めるものです。本アプリをご利用いただく前に、本ポリシーをお読みください。本アプリをインストールしてご利用になった場合、本ポリシーの内容に同意いただいたものとみなします。

このポリシーの要点(3行まとめ)

  • 本アプリは当方のサーバーを一切持たず、記録した家計データを当方や第三者へ送信することはありません。
  • アカウント登録は不要で、氏名・メールアドレス・電話番号・位置情報などの個人を識別する情報は一切取得しません。
  • 画面の上部に広告を表示します。広告のために Google が広告 ID などを取得しますが、記録した家計の内容が広告に使われることはありません。詳しくは「6. 広告の表示と、第三者への提供」をご覧ください。アクセス解析や当方による行動追跡(トラッキング)は行いません。

本アプリは、以下の情報を取得・収集・送信しません。

2. 情報の利用目的

本アプリは、取り扱う情報を以下の目的にのみ使用します。これ以外の目的で利用することはありません。

  • 利用者ご自身の収支の記録、集計、グラフ表示、カレンダー表示、予算との比較を行うため
  • レシートの画像から金額・日付・店名を読み取り、入力の手間を省くため
  • クレジットカードの利用明細 PDF から利用履歴を取り込み、カテゴリごとに仕分けるため
  • 固定費・サブスクリプションを翌月以降に自動で記録するため
  • 登録したサブスクリプションについて、実際の利用時間を表示し、契約の見直し判断を助けるため
  • 広告を表示し、本アプリを無料で提供し続けるため

4. 使用状況へのアクセス(PACKAGE_USAGE_STATS)について

重要な開示事項: 本アプリには、登録したサブスクリプション(動画配信・音楽配信サービスなど)について「今月どれくらい使ったか」を表示し、契約を続けるかどうかの判断材料にしていただく機能があります。この機能のために、Android の「使用状況へのアクセス」権限を使用します。

4-1. この権限で取得する情報

  • 取得するのは、利用者がサブスクリプションとして登録した項目に対応するアプリ(例: Netflix を登録した場合は Netflix アプリ)についての、当月1日から現在までの合計利用時間(分単位の数値)のみです。
  • 端末にインストールされているアプリの一覧を取得したり、記録することはありません。
  • アプリの中で何を視聴・操作したかといった内容、画面の情報、通信の内容は一切取得しません。取得できるのは「合計で何分間、前面に表示されていたか」という数値のみです。
  • 利用者が登録していないサブスクリプションのアプリ、および本アプリが対応表を持たないアプリについては、利用時間を取得しません。

4-2. 取得した情報の取り扱い

  • 取得した利用時間は、その場で画面に表示するためだけに使用し、端末内にも保存しません。画面を閉じると破棄されます。
  • 当方のサーバーや第三者へ送信することは一切ありません。
  • 広告配信、プロファイリング、行動分析には一切利用しません。

4-3. 許可は任意であり、いつでも取り消せます

  • この権限を許可しなくても、家計簿としての機能(記録・集計・グラフ・レシート撮影・PDF 取込・予算管理など)はすべてご利用いただけます。表示されないのは利用時間の欄のみです。
  • 許可はいつでも取り消せます。端末の「設定」→「アプリ」→「特別なアプリアクセス」→「使用状況へのアクセス」→「マネログ」から、オフに切り替えてください。(項目名は端末の機種や Android のバージョンにより多少異なります。)

5. データの保存場所・バックアップ

5-1. 保存場所

本アプリに記録されたすべてのデータは、お使いの端末内の、本アプリ専用の保存領域に保存されます。この領域は Android の仕組みにより保護されており、他のアプリから読み取ることはできません。当方はこれらのデータにアクセスする手段を持ちません。

5-2. Android 自動バックアップについて

本アプリは、Android 標準の「自動バックアップ」機能を有効にしています。そのため、お使いの端末で Google アカウントのバックアップ機能がオンになっている場合、本アプリに記録したデータが、利用者ご自身の Google アカウントのバックアップ領域(Google ドライブ)へ自動的に保存されることがあります。

  • これは、機種変更や端末の初期化のあとにデータを復元できるようにするための仕組みです。
  • バックアップされたデータは利用者ご自身の Google アカウントに紐づいて保管され、当方がその内容を閲覧・取得することはできません。
  • この機能を利用したくない場合は、端末の「設定」→「Google」→「バックアップ」からバックアップをオフにするか、同画面のアプリ別の設定で本アプリを対象から外してください。
  • Google によるバックアップデータの取り扱いについては、Google プライバシーポリシーをご確認ください。

6. 広告の表示と、第三者への提供

本アプリは広告を表示します。 本アプリは、Google が提供する広告配信サービス「Google AdMob」を利用して、画面の上部に広告を表示します。本アプリを無料で提供し続けるためのものです。広告を表示・配信するにあたり、Google は本アプリを通じて以下の情報を取得します。これらは Google が取得するものであり、当方(提供者)が受け取ったり、保存したり、閲覧したりすることはありません。

6-1. 広告のために取得される情報

  • 広告 ID(Advertising ID) — 端末ごとに割り当てられる、広告のための識別番号です。氏名・電話番号・メールアドレスとは結び付いておらず、利用者ご自身の操作でいつでもリセット・無効化できます(下記 6-3 参照)。
  • IP アドレス、およびそこから推定されるおおよその地域(市区町村より広い範囲)
  • 端末の種類、OS のバージョン、言語設定、画面の大きさなどの一般的な端末情報
  • 広告が表示された回数、押された回数などの記録

取得される情報の詳細および最新の内容は、Google のポリシーと規約(Google のサービスを使用するパートナーのサイトやアプリで収集される情報)をご参照ください。

6-2. 家計データは広告に使われません

利用者が本アプリに記録した収入・支出の金額、日付、カテゴリ、メモ、店名・利用先名、口座(財布)の区分、予算、固定費・サブスクリプションの登録内容、レシートの画像、クレジットカード明細 PDF の内容が、広告配信に使われることは一切ありません。これらの情報は端末の外へ出ません(前記「1. 本アプリが取り扱う情報」)。本アプリには、これらを送信する処理そのものが実装されていません。

6-3. 広告 ID をリセット・無効にする方法

Android の端末設定から、いつでも次の操作を行えます(項目名は端末によって異なります)。

  • 「設定」→「セキュリティとプライバシー」→「その他のプライバシー設定」→「広告」と進み、「広告 ID を削除」または「広告 ID をリセット」を選びます。
  • 広告 ID を削除すると、興味・関心に基づく広告(パーソナライズ広告)は表示されなくなります。広告そのものは引き続き表示されますが、利用者に合わせて選ばれることはなくなります。

6-4. 配信地域について

本アプリは日本国内でのみ配信しています。そのため、EU・英国・スイスなど、広告の表示前に事前の同意取得が法令で求められる地域向けの同意画面(同意管理プラットフォーム)は組み込んでいません。今後これらの地域へ配信を広げる場合は、同意画面を組み込んだうえで本ポリシーを更新します。

6-5. 当方が行わないこと

当方は、本アプリで取り扱う情報を、法令に基づく場合を除き、第三者に提供・開示・販売・貸与することはありません。そもそも当方がこれらのデータを受け取る仕組みが存在しないため、提供の余地がありません。

上記の広告配信を除き、本アプリは以下を一切行いません。

  • アクセス解析ツール(Google アナリティクス、Firebase Analytics 等)の組み込み
  • クラッシュレポートの外部送信
  • 当方による、利用者の行動を横断的に追跡するトラッキング

8. データの保持期間と削除方法

当方はデータを保持しません。データの保持・削除は、すべて利用者ご自身の管理下にあります。

  • 個別の記録を削除する場合: アプリ内の記録一覧から、対象の記録を削除してください。
  • すべてのデータを削除する場合: 端末の「設定」→「アプリ」→「マネログ」→「ストレージ」→「データを消去」を実行してください。アプリ内のすべてのデータが削除されます。
  • アンインストールする場合: 本アプリをアンインストールすると、端末内に保存されたデータはすべて削除されます。
  • バックアップ側のデータを削除する場合: 上記「5-2」の自動バックアップを利用していた場合は、端末の「設定」→「Google」→「バックアップ」から、該当するバックアップを削除してください。

レシート撮影時に作成される一時的な画像ファイルは、文字認識の処理が終わった時点で自動的に削除されます。

9. 安全管理措置

  • 本アプリのデータは、Android のアプリサンドボックス(アプリごとにデータ領域を分離する仕組み)によって保護され、他のアプリからアクセスできません。
  • 本アプリは家計データを外部に送信しないため、通信経路上で家計の内容が漏えいするリスクがありません。通信するのは広告の読み込みのみで、その通信に家計データは含まれません。
  • 当方はデータを預からないため、当方側の情報漏えいによって利用者のデータが流出することはありません。
  • 端末の紛失・盗難に備え、画面ロック(パスワード・生体認証など)の設定をおすすめします。

当方は利用者のデータを収集・保管しないため、当方による国外へのデータ移転は発生しません。ただし、以下の場合に、日本国外のサーバーとの通信または保管が発生します。いずれも取り扱いは Google のプライバシーポリシーに従います。

Privacy Policy (English Summary)

  • No data collection by the developer. Manelog has no backend server. All data you enter (income, expenses, categories, memos, merchant names, budgets, subscriptions) is stored solely in your device's app-private storage. It is never transmitted to the developer or any third party.

All other features work without granting this permission, and it can be revoked at any time via Settings → Apps → Special app access → Usage access.
  • Internet permission. Used only to load advertisements. Your financial records are never transmitted; the app contains no code that sends them anywhere.
  • Android Auto Backup. Enabled. If backup is turned on for your Google account, your Manelog data may be backed up to your own Google Drive backup storage so it can be restored after a device change. This data belongs to your Google account; the developer cannot access it. You can disable this in Settings → Google → Backup.
