対象アプリ: CLIFF 断崖絶壁(Android アプリ / パッケージ名 app.primarydice.cliff)

提供者(デベロッパー): Primary Dice

制定日: 2026年10月29日 / 最終更新日: 2026年10月29日

本プライバシーポリシー(以下「本ポリシー」)は、上記提供者(以下「当方」)が提供する Android アプリケーション「CLIFF 断崖絶壁」(以下「本アプリ」)における、利用者の情報の取り扱いについて定めるものです。本アプリは、指で登山者の手足を動かし、高さ 100m の断崖を頂上まで登る 3D のゲームです。本アプリをご利用いただく前に、本ポリシーをお読みください。本アプリをインストールしてご利用になった場合、本ポリシーの内容に同意いただいたものとみなします。

このポリシーの要点

  • 本アプリは当方のサーバーを一切持たず、ゲームの進み具合や記録を、当方や第三者へ送信することはありません。データはすべて端末の中に保存されます。
  • アカウント登録は不要で、氏名・メールアドレス・電話番号・位置情報などの個人を識別する情報は一切取得しません。
  • タイトル画面・一時停止の画面などで画面の下部に広告を表示します(崖を登っている間は表示しません)。また、落ちたときに利用者が選んだ場合に限り、動画の広告を表示します。広告のために Google が広告 ID などを取得しますが、ゲームの記録が広告に使われることはありません。詳しくは「5. 広告の表示と、第三者への提供」をご覧ください。
  • 3D 表示の部品と頂上の動画はアプリの中に入っており、広告を除いて電波の無い場所でも遊べます。アクセス解析ツールの組み込みや、当方による行動追跡(トラッキング)は行いません。

3-3. 広告配信の仕組みが自動的に追加する権限

広告を表示するために組み込んでいる Google の部品(Google Mobile Ads SDK)が、以下の権限を自動的に追加します。当方が個別に指定したものではなく、広告配信のために Google が必要としているものです。

  • WAKE_LOCK — 広告の読み込み中に端末がすぐ休止状態にならないようにするための権限。
  • FOREGROUND_SERVICE — 広告関連の処理をバックグラウンドで行うための権限。

これらはいずれも、利用者に許可を求める画面が出ない種類の権限です。当方はこれらの権限を通じて情報を取得していません。

4. データの保存場所・バックアップ

4-1. 保存場所

本アプリに保存されたすべてのデータは、お使いの端末内の、本アプリ専用の保存領域に保存されます。この領域は Android の仕組みにより保護されており、他のアプリから読み取ることはできません。当方はこれらのデータにアクセスする手段を持ちません。

4-2. Android 自動バックアップについて

本アプリは、Android 標準の「自動バックアップ」機能を有効にしています。そのため、お使いの端末で Google アカウントのバックアップ機能がオンになっている場合、本アプリに保存したデータ(ゲームの進み具合、持ち物、記録、効果音の設定)が、利用者ご自身の Google アカウントのバックアップ領域(Google ドライブ)へ自動的に保存されることがあります。また、機種変更のときに、新しい端末へ引き継がれることがあります。

  • これは、機種変更や端末の初期化のあとに、ゲームの続きを遊べるようにするための仕組みです。
  • バックアップされたデータは利用者ご自身の Google アカウントに紐づいて保管され、当方がその内容を閲覧・取得することはできません。
  • この機能を利用したくない場合は、端末の「設定」→「Google」→「バックアップ」からバックアップをオフにしてください。
  • Google によるバックアップデータの取り扱いについては、Google プライバシーポリシーをご確認ください。

5. 広告の表示と、第三者への提供

本アプリは広告を表示します。 本アプリは、Google が提供する広告配信サービス「Google AdMob」を利用して、次の2種類の広告を表示します。本アプリを無料で提供し続けるためのものです。

  • バナー広告: タイトル画面・一時停止の画面・遊び方や持ち物の画面・落ちたときの画面・頂上に着いたときの画面で、画面の下部に表示します。崖を登っている間は表示しません。
  • 動画の広告(リワード広告): 落ちたときの画面で、利用者が「動画を見て、落ちる前に戻る」を選んだ場合にだけ表示します。最後まで見ると、落ちる前の場所に戻れます。見るかどうかは利用者の自由で、見なくてもゲームは続けられます。

広告を表示・配信するにあたり、Google は本アプリを通じて以下の情報を取得します。これらは Google が取得するものであり、当方(提供者)が受け取ったり、保存したり、閲覧したりすることはありません。

5-1. 広告のために取得される情報

  • 広告 ID(Advertising ID) — 端末ごとに割り当てられる、広告のための識別番号です。氏名・電話番号・メールアドレスとは結び付いておらず、利用者ご自身の操作でいつでもリセット・無効化できます(下記 5-3 参照)。
  • IP アドレス、およびそこから推定されるおおよその地域(市区町村より広い範囲)
  • 端末の種類、OS のバージョン、言語設定、画面の大きさなどの一般的な端末情報
  • 広告が表示された回数、押された回数、動画の広告を最後まで見たかどうかなどの記録

取得される情報の詳細および最新の内容は、Google のポリシーと規約(Google のサービスを使用するパートナーのサイトやアプリで収集される情報)をご参照ください。

5-2. ゲームの記録は広告に使われません

本アプリに保存されたゲームの進み具合、持ち物、記録、設定が、広告配信に使われることは一切ありません。これらの情報は端末の外へ出ません(前記「1. 本アプリが取り扱う情報」)。本アプリには、これらを送信する処理そのものが実装されていません。

5-3. 広告 ID をリセット・無効にする方法

Android の端末設定から、いつでも次の操作を行えます(項目名は端末によって異なります)。

  • 「設定」→「セキュリティとプライバシー」→「その他のプライバシー設定」→「広告」と進み、「広告 ID を削除」または「広告 ID をリセット」を選びます。
  • 広告 ID を削除すると、興味・関心に基づく広告(パーソナライズ広告)は表示されなくなります。広告そのものは引き続き表示されますが、利用者に合わせて選ばれることはなくなります。

5-4. 配信地域について

本アプリは日本国内でのみ配信しています。そのため、EU・英国・スイスなど、広告の表示前に事前の同意取得が法令で求められる地域向けの同意画面(同意管理プラットフォーム)は組み込んでいません。今後これらの地域へ配信を広げる場合は、同意画面を組み込んだうえで本ポリシーを更新します。

5-5. 当方が行わないこと

当方は、本アプリで取り扱う情報を、法令に基づく場合を除き、第三者に提供・開示・販売・貸与することはありません。そもそも当方がこれらのデータを受け取る仕組みが存在しないため、提供の余地がありません。
